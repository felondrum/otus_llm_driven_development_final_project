# System Architecture Document — Chameleon Chat

## Адаптивная коммуникационная система в реальном времени

---

## 1. Executive Summary (Краткий обзор)

**Chameleon Chat** — это система реального времени, которая автоматически адаптирует сообщения пользователей в соответствии с корпоративными правилами, профилем собеседника и выбранным литературным стилем. Сообщение, которое видит получатель, может существенно отличаться от того, что написал отправитель, при этом оригинал сохраняется только для аналитики.

**Ключевая инновация:** Система не просто фильтрует или цензурирует, а **трансформирует стиль и тон** сообщения, сохраняя исходный смысл и намерение.

**Архитектурный паттерн:** Микросервисная архитектура с синхронным (реалтайм) и асинхронным (аналитика) потоками обработки.

**Развертывание:** Локальный Docker Compose для каждого модуля. Все модули работают в единой Docker сети `chameleon-network`.

---

## 2. Бизнес-смысл

Система Chameleon Chat решает задачу корпоративной коммуникации, где важны:

- **Профессиональный тон** — адаптация сообщений под уровень формальности
- **Эмоциональный интеллект** — смягчение конфликтных формулировок
- **Корпоративная культура** — соблюдение внутренних правил общения
- **Личная адаптация** — учет стиля общения конкретного получателя

**Сценарии использования:**
- Младшие сотрудники общаются с руководством — автоматическое формальное обращение
- Коллеги обмениваются техническими сообщениями — специфический жаргон
- HR коммуникации — эмпатичный и поддерживающий тон
- Работа с клиентами — дипломатичный и вежливый стиль

---

## 3. Технологии

**Backend (Python 3.11+):**
- FastAPI — HTTP API фреймворк
- Redis — кэш и очереди
- PostgreSQL — метаданные и аналитика
- Qdrant — векторная база данных для RAG
- Ollama — локальные LLM модели (qwen2.5:1.5b)
- Yandex LLM API — внешний провайдер (fallback)

**Frontend:**
- React 18 + Vite — веб-интерфейс
- WebSocket — реальное время
- Tailwind CSS — стилизация

**Инфраструктура:**
- Docker Compose — контейнеризация
- Langfuse — трейсинг и мониторинг LLM

## 5. Функциональность

### Основные возможности

**Адаптация сообщений:**
- Автоматическая замена формального/неформального обращения
- Смягчение конфликтных формулировок
- Учет корпоративных правил
- Применение литературных стилей (Чехов, Довлатов, Пелевин)

**Управление данными:**
- Загрузка и управление профилями пользователей
- Управление корпоративными правилами
- Управление литературными стилями
- Загрузка документов для RAG

**Мониторинг и аналитика:**
- Трейсинг вызовов LLM (Langfuse)
- Метрики производительности (Prometheus)
- Логирование адаптаций

**Чат-интерфейс:**
- Real-time обмен сообщениями
- Выбор получателя
- Просмотр адаптированных сообщений
- Синхронизация профилей

## 6. Модули проекта

### Module 1: Core Engine

Сердце системы — обработка сообщений, RAG поиск, маршрутизация к LLM.

**Компоненты:**
- **Orchestrator** — координирует процесс адаптации
- **Retriever** — предоставляет RAG данные из Qdrant
- **LLM Gateway** — маршрутизирует запросы к LLM провайдерам

**Документация:**
- [README](module-1-core-engine/README.md)

### Module 2: Chat Frontend

Веб-интерфейс чата с WebSocket и REST API.

**Компоненты:**
- **Backend** — Python FastAPI с WebSocket
- **Frontend** — React + Vite
- **Profile Sync** — синхронизация с Core Engine

**Документация:**
- [README](module-2-chat-frontend/README.md)

### Module 3: Admin Data

Админ-интерфейс для управления данными системы.

**Компоненты:**
- **Admin API** — FastAPI сервер для CRUD операций
- **Admin UI** — React интерфейс для работы с данными

**Документация:**
- [README](module-3-admin-data/README.md)

## 8. Быстрый старт

```bash
# Запустить модуль 1 (Core Engine)
cd module-1-core-engine
cp .env.example .env
docker-compose -f docker-compose.module.yml up -d

# Запустить модуль 2 (Chat Frontend)
cd ../module-2-chat-frontend
docker-compose -f docker-compose.module.yml up -d

# Запустить модуль 3 (Admin Data)
cd ../module-3-admin-data
docker-compose -f docker-compose.module.yml up -d
```

**Доступные сервисы:**
- Chat UI: http://localhost:8080
- Admin UI: http://localhost:5174
- Langfuse: http://localhost:3000
